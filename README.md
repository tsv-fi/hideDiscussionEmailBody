# Hide Discussion Email Body Plugin

OJS, OMP, OPS 3.4

This plugin hides the body of discussion notification emails ensuring that users will respond to your discussion messages using the discussion tool.

The replacing message in the string can be localized and the default message is:
```
msgid "plugins.generic.hideDiscussionEmailBody.discussion.updated"
msgstr "{$senderName} sent a new message."
```
